# Krillion Session Helper documentation

Maintainer documentation for the public [Krillion Session Helper](https://github.com/cnvxstudio/krillion-session-helper), covering host requirements, mode selection, real invitations and prompt-specific score reporting.

The associated [Krillion browser game](https://krillionanswers.net/play/) is separate from this documentation and is not included as source code. This is a documentation-only companion maintained with the project, not an independent review.

`index.html` is a self-contained static document. `.readthedocs.yaml` copies it into the HTML build output without third-party build dependencies. Content and configuration: MIT-0.
